DIPS Threat Inventory

The DIPS Threat Inventory is a structured cybersecurity knowledge base developed within the DIPS (Detecting Intrusion and Protecting Systems) project. It provides a comprehensive mapping of cyber threats affecting satellite and space systems and serves as the foundation for threat analysis, risk prioritization, and intrusion detection research.

The inventory captures relationships between:

Threat types and attack vectors
Satellite components and subsystems
Security layers
Threat categories
Qualitative risk levels (High, Medium, Low)
Potential AI/ML-based detection approaches
Mitigation and protection measures
Relevant cybersecurity standards and frameworks
Stakeholder responsibilities
System lifecycle stages

The purpose of the inventory is to support the development of risk-prioritized intrusion detection strategies for satellite systems by identifying which threats have the greatest operational impact and where detection efforts should be focused.

Dataset Scope

The inventory includes threats affecting multiple satellite domains, including:

Hardware and supply-chain attacks
Software and firmware attacks
Ground segment attacks
Communication and network attacks
RF and signal-layer attacks
Navigation and positioning attacks
Inter-satellite communication threats
Mission operation and command-chain attacks
Intended Use

This dataset can be used for:

Satellite cybersecurity research
Threat modelling and risk assessment
Intrusion Detection System (IDS) design
AI/ML-based cyber threat detection studies
Security architecture development
Space mission cybersecurity planning
